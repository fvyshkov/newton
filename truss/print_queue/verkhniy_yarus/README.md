# Высотный узел — ФИНАЛ (GoTo + работает руками), единое седло

Всё, что выше треугольной базы. **Одно седло** служит и для ручного наведения, и для
GoTo — ничего не переделывать при апгрейде. Опора колеса Ø200 асимметричная:
**+Y — тефлон-пятак** (трение держит высоту руками), **−Y — ведущий фрикц-ролик**
(в ручном свободен = опора; в GoTo его крутит NEMA17 → трением катит колесо).
Энкодер AS5048A на вышке читает магнит в центре колеса. Схема: `_MECHANISM.png`.
Раскладка печати: `_BED_LAYOUT.png`.

Регенерация: `python3 ../../generate_rocker_towers.py` (кроме энкодер-arm — он на
build123d: `../../../.venv-cad/bin/python ../../generate_alt_encoder_arm.py`).
Все детали watertight; коллизии в сборке проверены (седло∩диск≈0, привод садится).

## Покупное / готовое

- **PTFE (тефлон) ~2 мм**: 2 пятака в карман **16×18 мм** (по 1 на седло, +Y сторона), чуть проуд.
- **Ролики −Y**: вал Ø8 + O-ring на `06`; 608ZZ по вкусу (ролик на валу или на 608 — стенд).
- **NEMA17 ×1** (только R) + GT2 20T→60T + ремень (CD 58.6, ~3:1).
- **Магнит Ø6×2.5** диаметральный ×1 (в `08`) + **плата AS5048A ×1** (на `07`).
- **Трубки Ø22**: ноги 467×2 / 529×2, поперечина 340×1 (`../../tube_cut_list.md`).
- **Колёса Ø200×15 ×2** — с трубой (Leavitt); центр рассверлить Ø6 под спигот `08`.
- Винты: M5 (хомуты), M4 (площадка энкодера + лапа привода), M3 (NEMA + сетскрю), M2.5 (плата).

## Столы печати — готовые файлы (открыть в Bambu Studio → слайс)

**СЕДЛО ПЕЧАТАЕТСЯ «НА БОКУ»** (rotate X90+Y180, H=160), НЕ лёжа! Рамка антиподъёма
встаёт замкнутым прямоугольником, блок хомута — вниз. Тогда весь лес (~5.6k мм²)
сидит ниже z=70 в блоке (бор Ø22 + уши роликов), башен к верхней арке нет.
«Лёжа» давало 11.6k мм² леса под всей длиной рамки — вдвое больше. Разбор:
`_CRADLE_ORIENT.png` / `_CRADLE_SIDE.png`. Футпринт на боку 257×98.

- **`STOL_ALL.3mf`** = ВСЁ одним столом (9 дет.): 2 седла на боку + 2 вышки +
  привод + энкодер-arm + 2 ролика + магнит. bbox 340×292×160, влезает в 350×320,
  пересечений нет. Раскладка — `_STOL_ALL_layout.png`. Минус: один длинный принт
  «всё или ничего» (~617 см³ тела, до 160 мм высотой).
- **`STOL_1.3mf`** = cradle_R (на боку) + apex_R + alt_drive + magnet + ролик
- **`STOL_2.3mf`** = cradle_L (на боку) + apex_L + encoder_arm (на бок) + ролик
  — вариант с изоляцией брака: по седлу на стол.

Пересобрать: `python3 ../../_make_plates.py` (один стол) либо
`python3 -c "import _make_plates as m; m.build_split()"` (два стола).

Печать: PETG, 4 стенки, 25% gyroid, слой 0.2; текстурированный PEI; brim 5 мм под
вышки; **support Auto** — лес ляжет только внизу в блоке седла, снаружи доступен;
encoder_arm ориентирован «на спину».

## Проверки (пройдены)

- Все watertight; apex/седло **tube-fit PASS**; седло **∩ диск R99.3 ≈ 0** (пятак касателен,
  вилка ролика снаружи диска); **alt_drive садится** на −Y ухо (0 вреза); энкодер-arm
  ∩ диск/седло/магнит = 0 (`../../_verify_alt_encoder.py`).

3. Доступ к винтам платы энкодера (−X сторона) — ставить до монтажа колеса.
