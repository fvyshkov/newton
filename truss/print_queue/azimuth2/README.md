# Азимут v2 — файлы для печати на Bambu H2D

Осевой поворотный узел («ленивая Сюзанна»). Модель и описание узла:
`truss/azimuth2/` (генератор `generate_az2.py`, README с механикой и сборкой).

## Что печатать — 3 стола (PETG, ≈640 г всего)

Каждый `.3mf` уже разложен на стол (детали вложены дуга-в-дугу) — открыть в
Bambu Studio и нарезать, раскладывать вручную не нужно. `.stl` — тот же стол одним
файлом (бэкап, если 3mf не откроется).

## Стол 4 — если гнёзда ног на венце сломались (актуально 13.07)

Гнёзда ног, напечатанные заодно с сегментами венца, без точечных поддержек
срываются (наклон 15.6°/35.6°). Если так вышло — сегменты НЕ перепечатывать
(зубья/стыки/карманы целы): печатаешь `plate4` вместо `plate3`. На нём:

- **`az2_shoe_A30` / `C150` / `D270`** — башмаки: тот же наклонный хомут
  (бор Ø22.6, стопор M4), но на плоском фланце-подошве. Наклоны 1:1 из венца
  (апексы ±170, размах колёс 340 сохраняются; посадка трубы стартует на 8 мм
  выше → ноги короче на ~8–10 мм, резать по месту). D270 — двойной (обе ноги
  ведущего угла). Печать фланцем вниз, **БЕЗ поддержек**, 4 стенки, **инфилл ≥40 %**.
- **`az2_magnet_spider3`** — спайдер с ТРЕМЯ лучами (на бобышки 120/210/300).
  Найден косяк исходного венца: бобышка спайдера сегмента A (R196, азимут 30°)
  лежит внутри пятна ноги 30° — 4-й луч туда не прикрутить. Трёх хватает.
  Ставить лучами именно на 120/210/300 (в положении «30/120/210» луч упрётся
  в хомут — не встанет, промахнуться нельзя).
- подставка мотора + шестерня + колонна — как на столе 3 (поддержки — только
  под верхнюю плиту подставки).

**Установка башмаков:**
1. Остатки сломанных гнёзд срезать и зачистить **заподлицо** с верхом венца
   (лапа должна лечь плоско).
2. Башмак прижать наружным краем фланца к стенке зубчатого обода (упор по
   радиусу), хомут — по центру шрама старой ноги (упор по углу).
3. Через отверстия фланца предсверлить Ø2.5, шурупы **3.5×12, НЕ длиннее**
   (снизу скользящая грань и тефлон-карманы; 12 мм не пробивает). Отверстия
   уже разведены от тефлон-карманов — сверлить только сквозь них.

**Стол 2 — 4 РАЗНЫХ сегмента венца** (не одинаковые!): гнёзда ног башен встроены на
3 углах R201 (30/150/270):
- `A_leg30` — 1 наклонное гнездо (нога → apexR);
- `B_plain` — без ног;
- `C_leg150` — 1 гнездо (нога → apexL);
- `D_leg270` — **2 гнезда** (ведущий угол, ноги → apexR и apexL).

Ноги входят в апекс ~1.3° мимо расчёта под R210 (гнёзда сдвинуты внутрь, чтоб не
трогать зубья) — съедается люфтом трубы Ø22 в боре. Проверено: хомут зубья НЕ трогает,
труба Ø22 в бор входит (tube-fit ок).

`stl_отдельно/` — все детали по отдельности. `az2_bed_layout.png` — раскладка.

## Настройки печати

- **Материал: PETG** (силовые детали; PLA поплывёт летом на балконе/в машине).
- 3–4 стенки, **инфилл 25 %**, шов Random.
- **Поддержки — точечно:**
  - сегменты колец: под **язык-нахлёст** стыка (верхняя половина торца нависает);
  - **гнёзда ног на венце** (`A/C/D`): хомут наклонён 15° (30/150) или 34° (270) —
    **нужны поддержки под наклонный хомут** (иначе нависание сорвётся);
  - `motor_pedestal`: под **верхнюю плиту** (нависает над окном вала);
  - зубья, буртик, спайдер, колонна — БЕЗ поддержек.
- Ориентация в 3mf уже правильная (дно на столе). Ничего не переворачивать.

## Порядок (важно!)

1. **Сначала калибровка, НЕ весь стол.** Напечатать по 1 сегменту из
   `stl_отдельно/` (`az2_ring_fixed_seg` + `az2_ring_rot_A_leg30`) + `az2_pinion_16T_bore5`
   + `az2_motor_pedestal`. Надеть свой NEMA17 (Ø5 вал), проверить:
   - шестерня попадает в зубья (если нет — подрезать высоту подставки в модели);
   - усадку/зазоры стыка; натяг прорезями подставки;
   - на `A_leg30` — влезает ли труба Ø22 в наклонное гнездо (поддержки под хомут!).
2. Убедились — печатать `plate1` и `plate2` (4 РАЗНЫХ сегмента венца), потом `plate3`.
   Нижнее кольцо у тебя уже напечатано — можно `plate1` пропустить.

## Дальше (не в этой папке)

Тефлон-пятачки (24 шт) в карманы дна вращающегося кольца, дорожку неподвижного
обклеить ламинатом/PET. Плата AS5048A на колонну, магнит на спайдер — выставить
зазор ~1.2 мм. Стойки Ø22 + седло — из существующего «верха» (`verkhniy_yarus`).
Привод прямой 14:1 на обычном NEMA17 (уже куплен) — ничего докупать не надо.
