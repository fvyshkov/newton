# Азимут v2 — файлы для печати на Bambu H2D

Осевой поворотный узел («ленивая Сюзанна»). Модель и описание узла:
`truss/azimuth2/` (генератор `generate_az2.py`, README с механикой и сборкой).

## Что печатать — 3 стола (PETG, ≈640 г всего)

Каждый `.3mf` уже разложен на стол (детали вложены дуга-в-дугу) — открыть в
Bambu Studio и нарезать, раскладывать вручную не нужно. `.stl` — тот же стол одним
файлом (бэкап, если 3mf не откроется).

| Файл | Что | габарит | ≈г |
|---|---|---|---|
| `plate1_ring_fixed_x4` | неподвижное кольцо ×4 сегмента | 317×281 | 295 |
| `plate2_ring_rot_x4` | вращающееся кольцо ×4 (с зубьями) | 322×279 | 269 |
| `plate3_center_4parts` | спайдер + колонна + подставка + шестерня | 279×279 | 74 |

`stl_отдельно/` — все 6 деталей по отдельности (если нужно перекомпоновать).
`az2_bed_layout.png` — картинка раскладки. `az2_scheme.png` — схема механизма.

## Настройки печати

- **Материал: PETG** (силовые детали; PLA поплывёт летом на балконе/в машине).
- 3–4 стенки, **инфилл 25 %**, шов Random.
- **Поддержки — точечно:**
  - сегменты колец: под **язык-нахлёст** стыка (верхняя половина торца нависает);
  - `motor_pedestal`: под **верхнюю плиту** (нависает над окном вала);
  - зубья, буртик, гнёзда стоек, спайдер, колонна — БЕЗ поддержек (печатаются как есть).
- Ориентация в 3mf уже правильная (дно на столе). Ничего не переворачивать.

## Порядок (важно!)

1. **Сначала калибровка, НЕ весь стол.** Напечатать по 1 сегменту из
   `stl_отдельно/` (`az2_ring_fixed_seg` + `az2_ring_rot_seg`) + `az2_pinion_16T_bore5`
   + `az2_motor_pedestal`. Надеть свой NEMA17 (Ø5 вал), проверить:
   - шестерня попадает в зубья (если нет — подрезать высоту подставки в модели);
   - усадку/зазоры стыка; натяг прорезями подставки.
2. Убедились — печатать `plate1` и `plate2` (можно минус уже напечатанные сегменты),
   потом `plate3`.

## Дальше (не в этой папке)

Тефлон-пятачки (24 шт) в карманы дна вращающегося кольца, дорожку неподвижного
обклеить ламинатом/PET. Плата AS5048A на колонну, магнит на спайдер — выставить
зазор ~1.2 мм. Стойки Ø22 + седло — из существующего «верха» (`verkhniy_yarus`).
Привод прямой 14:1 на обычном NEMA17 (уже куплен) — ничего докупать не надо.
