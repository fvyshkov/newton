# АЗИМУТАЛЬНЫЙ ПРИВОД — комплект деталей (belt-offset, 42:1)

NEMA17 → ремень GT2 3:1 → шестерня 16T → венец 224T = **42:1**. Ремень **2GT-200** (твой).

Мотор НЕ по оси: по оси корпус Ø42 упирается в трубные воротники угла (посчитано ~11 см³).
Уведён **вбок на (55,−220)** по дуге того же CD 58.6 → зазор к трубам **0 см³** (посчитано на
меше). Ремень идёт по диагонали. Натяг/зацепление — **прорезями** (сдвинул мотор, затянул).

## Купить (не печатаем)
2×**608ZZ** (22×8×7) · вал **Ø8** ~55 мм · шкив **60T**(бор Ø8) · шкив **20T**(бор Ø5) ·
ремень **2GT-200** ✅ · NEMA17 ✅ · винты M3 / сетскрю M3.

## Схема — что с чем (вид сверху)
```
        зубья ВЕНЦА (R224, фикс. на земле)
             ║
   шестерня 16T ●(0,−240)  на Ø8 валу в 2×608ZZ (корпус узла)
        шкив 60T ┘
             ╲  ремень 2GT-200 ПО ДИАГОНАЛИ
              ╲
         шкив 20T ▣ мотор NEMA17 (55,−220)  ← ВБОК, мимо труб
                     на балке-выносе от корпуса,
                     4×M3 в ПРОРЕЗЯХ вдоль ремня
   узел: 2 хорды + 2 ноги башни + глайд-тефлон (низ) — трубы свободны
```
Редукция: ремень 3:1 × шестерня/венец 14:1 = **42:1**. Глайд узла скользит по дорожке
венца, шестерня крутит раму вокруг оси M10.

## Сборка
1. 2×608ZZ запрессовать в корпус узла (снизу/сверху).
2. Ø8 вал сквозь оба: снизу **шестерня 16T** (сетскрю), выше — **60T** шкив.
3. **NEMA17** на фланец (4×M3 в прорезях, буртик в окно Ø23), вал вниз, **20T** шкив.
4. Ремень **2GT-200** на оба шкива (шкивы выставить соосно по высоте — сетскрю).
5. Высота шестерни — сетскрю: центр зуба ~z56 (12 мм зуб на 10 мм пояс венца, ±2 мм запас).
6. **Натяг ремня + зацепление**: сдвинуть мотор по прорезям (вдоль ремня), поймать ход без
   люфта и затянуть M3.

## Прочность стыков (проверено на меше)
Корпус подшипника сварен с узлом/падом **буттресом-массивом**: сечение шейки **1137–1283 мм²**
(сам корпус Ø30 в сечении ~700 мм²). После снятия саппорта НЕ отделяется. Балка-вынос к
фланцу **40 мм** — шире прорези Ø23, стык не перерезан. Всё — одно watertight-тело.

## ⚠️ Проверить на сухую
- **Шкив 20T мотора висит над кромкой венца** (~2 мм) — убедиться, что не задевает обод при вращении.
- Шестерня/60T на валу — консоль ниже подшипников, проверить биение.
- Прорези дают **±3.5 мм** хода мотора вдоль ремня — хватает на натяг 200-мм ремня и допуск.
- Каретка висит консолью → печать с поддержкой (дерево). Ориентация: пад/фланец плоскостью
  вниз даёт меньше саппорта под кареткой.
- Пружинный поджим шестерни к венцу (компенсация неровности сегментного венца) — улучшение v2.
