# РАМА (нижнее вращающееся кольцо) — 7 узлов

Согласовано с реальным венцом (Ø448, тело R200-217, pitch R224):
глайды R210 на дорожке венца ✓; шестерня зацепление 240=224+16 ✓; углы 30/150/270 ✓.

## Трубки Ø22 к раме

- полухорда (угол → середина хорды): рез 182 мм ×6
- радиаль (центр → середина хорды): рез 105 мм ×3

## Сборка

Глайды (тефлон-пятаки ~15×18) на низ 3 угловых узлов, скользят по дорожке
венца (верх тела, наклеить гладкую полоску-ламинат). Центр надет втулкой на
болт M10. Привод (мотор+шестерня) на узле 19, шестерня цепляет зубья венца.
