# НИЖНЯЯ РАМА (азимут) — собрать с венцом, покрутить мотором + энкодером

Цель: собрать вращающуюся раму на венце и оживить АЗИМУТ (мотор + энкодер),
не строя верхний ярус (башни/колёса). Как стенд, но уже боевая трубная рама.

## Уже есть / докупить
- Венец (4 сегмента) — НАПЕЧАТАН.
- Болт M10×110 + гайка, 3 глайда (тефлон-пятаки ~15×18), саморезы, M3/M4/M5.
- Трубки Ø22: полухорды 182×6, радиали 105×3 (по tube_cut_list.md).
- Железо: NEMA17 + FYSETC E4 + БП 12В; ESP32 + AS5048A + магнит — на руках.
- Фанера-основание: диск, венец болтами, ось M10 в центре, дорожка (ламинат).

## Сборка азимута
1. Фанерный диск: в центр ось M10, по кругу венец (4 сегмента) болтами.
2. На верх тела венца — гладкая полоска (ламинат/формика), дорожка скольжения.
3. Рама: 7 узлов + трубки → треугольник. Центр (21) втулкой на болт M10.
4. Глайды (тефлон) на низ 3 углов — скользят по дорожке венца.
5. Привод: swing_base+arm на узел 19, шестерня (pinion) в зубья венца, NEMA17.
6. Энкодер азимута: magnet_cap на торец болта M10, board_holder на полку узла 21,
   чип над магнитом ~1мм.
7. E4 (OnStepX, AXIS1 = 42:1 с ремнём) крутит раму по венцу; ESP32 читает угол.
