# TrussRocker — рокер-бокс из трубок и печатных узлов (Push-To + GoTo встроены)

Замена фанерного рокер-бокса: жёсткая ферма из алюминиевых трубок (те же Ø22–24
ручки швабры, что и в ферме телескопа) + печатные узлы. Все посадки под моторы,
энкодеры, зубчатый венец и подшипники **рассчитаны в CAD заранее** — ничего не
размечается карандашом «на глазок».

Ключевая идея против кривизны: азимутальная ось (болт M10), зубчатый венец и
дорожка скольжения сидят в **одной печатной ступице** — соосность получается
по построению, с точностью принтера (~±0.3 мм), а не по разметке. Остаток
кривизны съедают подпружиненная шестерня и абсолютные энкодеры на осях.

Весь пластик азимутального привода (венец 4 сегмента + шестерня + тест) —
**~170 г**. Это не «сплошной печатный рокер», это скелет.

📘 **Сборка по шагам (без слов, картинками):** [`rocker_assembly_comic.pdf`](rocker_assembly_comic.pdf)
(генератор: `gen_rocker_comic.py`)

## Архитектура

Два независимых узла: неподвижная «земля» и вращающаяся ферма.

### 1. Земля (неподвижная звезда)

```
        нога                    нога
          ╲                    ╱
           ╲ трубка Ø22       ╱
            ╲                ╱
             ●━━━ СТУПИЦА ━━●        ← печатная ступица в центре:
            ╱     (болт M10 ↑,          болт M10 = ось азимута,
           ╱   магнит AS5048A           сверху колпачок с магнитом
          ╱     на торце болта)
        нога

   вокруг ступицы, на лучах:  ЗУБЧАТЫЙ ВЕНЕЦ (печатный, 4 сегмента по 90°
   на болтах M3 + штифты, модуль 2, 224 зуба, делительный Ø448; сегмент
   ~322×90 мм — влезает на стол Bambu H2D 350×320, вдвое меньше стыков).
   Верхняя грань венца = кольцевая ДОРОЖКА (обклеить ламинатом/скотчем PET).
```

⚠️ Болт M10 — **частично резьбовой**: втулка фермы едет по гладкой части
стержня, не по резьбе (резьба = напильник, разбивает втулку).

### 2. Вращающаяся ферма (сам рокер)

```
      люлька L                люлька R      ← 2 узла, в каждом 2×608ZZ
         ●━━━━ поперечина ━━━━●               ролика + палец-ловушка сверху:
        ╱ ╲     + диагональ  ╱ ╲              колесо лежит на подшипниках
       ╱   ╲   между фермами╱   ╲             и не может ни съехать вбок,
      ╱     ╲              ╱     ╲            ни выпрыгнуть от толчка
     ●───────●━━━━━━━━━━━━●───────●         ← основание: рама из трубок;
      узел    узел с ПРИВОДОМ узел             в углах — печатные узлы,
       │        │              │               скользят/катятся по дорожке
     опора    NEMA17→ремень   опора            венца
              3:1→вал 8мм→
              шестерня 16T в венец
```

- Центральный узел фермы надет втулкой на болт M10 + держит плату AS5048A
  над магнитом (переиспользуем `board_holder.stl`).
- **Все электронные части (E4, ESP32, аккумулятор) едут на ферме** — через
  вращающийся стык не идёт ни один провод.
- Между двумя А-фермами сзади — **диагональная трубка** (вне размаха трубы):
  без неё ферма гуляет вбок от руки на окуляре и ветра, и энкодеры это
  НЕ компенсируют (это изгиб конструкции, а не поворот оси).
- Привод высоты: второй NEMA17 + ремень 3:1 + фрикционный ролик с O-кольцом,
  прижатый пружиной к ободу чёрного колеса **строго снизу-в-центр** (чтобы
  прижим вдавливал колесо в ролики люльки, а не выталкивал). Энкодер #2 —
  магнит в центре колеса (существующий `magnet_cap_altitude`), чип на люльке.

### 3. Колёса высоты — реальная конструкция (обмерено по моделям Leavitt v2)

Телескоп — ремикс Leavitt v2 («Truss new» у сына в Bambu): три штанги, по
ним ездят печатные кольца; колёса прикручены к среднему кольцу с двух
сторон. Кольцо **двигается по штангам** → ось ставится точно в ЦТ (взвешен:
**вся труба 5 кг** — вдвое легче, чем закладывалось, все запасы растут).

Снято с STL (Printables, Leavitt v2, точность модели):

| Параметр | Значение |
|---|---|
| Колесо (Alt bearing) | **Ø200.00 × 15.0 мм**, обод цилиндрический, фаски 0.3 |
| Центр колеса | отверстие **Ø5.5** (готовое место под магнит энкодера!) |
| Крепёж колеса | 4 отв. Ø9.7 на квадрате 25×25 (r=17.7) |
| Кольцо-основа (труба) | OD ≈ **250**, ID ≈ 228, высота 80 |
| Размах углов кольца вокруг оси | √(125² + 40²) ≈ **R131** — люлька без перемычек ближе R140 |
| Межколёсное (середина-середина) | **~340 мм** (замер: изнутри 320, снаружи ~360) |

Что осталось от вывода скептика: (1) после балансировки зафиксировать
среднее кольцо сквозным болтом через штангу — печатный зажим на гладкой
трубе ползёт со временем; (2) колесу нужен боковой захват на роликах
(реборды-накладки или ловушка в люльке); (3) **люльки на поперечине —
подвижные** (±10 мм, зажим M5): точное межколёсное не критично.

### Передаточные числа (проверено расчётным агентом)

| Ось | Цепочка | Итого |
|---|---|---|
| Азимут | NEMA17 → GT2 20T:60T (3:1) → шестерня 16T → венец 224T (14:1) | **42:1** |
| Высота | NEMA17 → GT2 20T:60T (3:1) → ролик Ø35 → колесо Ø200 (5.7:1) | **~17:1** |

## Математика привода (вердикт: PASS)

200 шагов/об, ×16 µстеп, рабочий момент мотора 0.3 Н·м, 12В / TMC2209 @ 1.2–1.4 A RMS.

| Величина | Азимут | Высота (колесо Ø200) |
|---|---|---|
| Полная редукция | **42:1** | **17.1:1** |
| µшагов на градус (OnStepX AXIS) | **373.33** | 152.4 |
| ″ на µшаг (×16) | 9.6″ | 23.6″ |
| ″ на шаг интерполяции 1/256 | 0.60″ | 1.48″ |
| Момент на оси (КПД 70–80%) | 8.8–10.1 Н·м | 3.6–4.1 Н·м |
| Слю при 180 RPM мотора | 26°/с | 63°/с |

Труба весит 5 кг (не 11) → нагрузки и трение вдвое ниже расчётных запасов;
3.6 Н·м на высоте при сбалансированной 5-кг трубе — запас в разы. Если
захочется плотнее — ролик Ø25 даёт 24:1 (16.9″/µшаг).

- Трекинг для визуала гладкий благодаря интерполяции TMC2209 (0.6″/1.05″).
- На 12В не планировать обороты мотора выше ~240 RPM — момент рушится.
- Прижим ролика высоты: нужно **60–90 Н (6–9 кгс)** — обычная пружина.
- Зуб шестерни (PLA, модуль 2, 10 мм): напряжение 8–10 МПа при допуске
  25–30 МПа → запас ×3–4. Пропуск шагов мотора при толчке — это «сцепление»,
  защищающее зубья; НЕ поднимать ток «чтобы не пропускало».

## Размеры: что известно и что осталось

Снято с моделей Leavitt v2 и взвешиванием (раздел «Колёса высоты»):
колесо Ø200×15 с центром Ø5.5, кольцо OD≈250, межколёсное ≈270,
труба в сборе 5 кг, принтер Bambu H2D 350×320. Трубки Ø22–24 докупаются
(~9–11 шт по 0.5–1 м).

Замеры получены (03.07.2026, рулеткой):

1. **Размах вниз ≈ 490 мм** (кольцо может стоять не ровно на ЦТ — заложен
   запас 40 мм: ось высоты на **590 мм** над дорожкой венца).
2. **Межколёсное: изнутри 320, снаружи ~360** → середины ободов на
   **~340 мм** (люльки подвижные ±10 мм — покрывают разброс замера).

## Риски и решения (адверсариальный разбор)

Критичные — уже вшиты в архитектуру выше: колёса на подраму к боксу (не на
трубы), ролики люльки в U-ободе + ловушка, ребро жёсткости на венце,
диагональ между А-фермами. Остальное:

| Риск | Решение |
|---|---|
| Шестерня выталкивается из зацепления (расталкивающая сила ~30–40 Н) и по-разному ведёт себя по направлениям | Ось качания кронштейна — на линии касательной силы через пятно зацепления; жёсткий упор глубины (M3-винт); пружина 60–70 Н только против биения |
| Пятаки-глайды по сырому FDM-пластику: страгивание до 12–15 Н·м, дребезг stick-slip | Обклеить дорожку венца ламинатом (Formica) или PET-скотчем для начала; если мало — 3 ролика 608ZZ вместо пятаков + один лёгкий тефлоновый демпфер |
| Обод PLA на роликах 608ZZ: контактные ~20 МПа → вмятины за неделю стоянки | По 2 подшипника рядом на ролик (вдвое ниже давление) ИЛИ полоска алюминия 1 мм в канавке обода; не парковать в одном положении |
| Роса ночью → NBR-на-PLA теряет сцепление втрое | Балансировать с самым тяжёлым окуляром (остаток < 1 Н·м, ползунок-противовес на трубе), печатный «крылос» над дугой контакта, высоту в OnStepX замыкать по энкодеру |
| Толчок = пропуск шагов = потерянная привязка | SERIAL_BRIDGE + синхронизация OnStepX по энкодерам — обязательный этап ДО сборки приводов, тест «дёрнул рукой — навёлся обратно» на столе |
| PLA плывёт летом (машина, балкон: 60–80°C) | Все силовые детали — **PETG**; PLA только щупы/крышки. Не хранить в машине |
| 608ZZ бюджет: люльки 4(8) + приводы 4 + ролики дорожки 3 | В наличии 10 → дозаказать десяток (копейки) |

## Порядок стройки (по этапам, чтобы отлаживать по одной подсистеме)

1. **Стол**: `Rocker_mesh_test` + шестерня → подобрать усадку, пружину, упор.
2. **Азимут без башен**: венец + ступица + треугольник с гантелей 12 кг
   вместо телескопа → слю/трекинг с энкодерной синхронизацией.
3. **Башни + люльки + колёса** с трубой → баланс, прижим ролика, зазоры.
