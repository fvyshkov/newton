# Truss-вариант 8" f/5.9 Dobsonian

Альтернатива сонотубу: разборная ферменная конструкция на 4 алюминиевых трубках. Цель — лёгкая транспортировка, простая коллимация, материалы доступные в Израиле без AliExpress.

📘 **Сборка по шагам (без слов, картинками):** [`truss_assembly_comic.pdf`](truss_assembly_comic.pdf)

## Оптика (исходные данные)

| Параметр | Значение |
|---|---|
| Главное зеркало | 203мм (8") |
| Фокусное расстояние | 1200мм (f/5.91) |
| Вторичное зеркало | 50мм малая ось |
| Окуляры | 25мм и 10мм, 1.25" |
| Фокусер | геликоидный (как в основном проекте, можно перепечатать) |

## Архитектура

```
        ┌───────────────────┐    ← UTA (Upper Tube Assembly)
        │   ●─── focuser    │      ID 240мм, h ≈ 130мм
        │  ╱│╲              │      держит вторичку (паук) + фокусер
        │ paук              │
        └─┬─┬─┬─┬───────────┘
          │ │ │ │              ← 4 стойки, L ≈ 900мм
          │ │ │ │                Ø22-28мм (универсальный сокет
          │ │ │ │                с хомутным зажимом)
          │ │ │ │
        ┌─┴─┴─┴─┴───────────┐
        │                   │  ← Mirror box (открытая рамка)
        │   [ оправа ]      │     250×250мм, h ≈ 120мм
        │                   │     держит оправу зеркала + truss
        └───────────────────┘
                │
                ▼
            (rocker box — основание Добсона, отдельно)
```

| Толщина стенки UTA (печатная) | 10 |
| Седло фокусера (на стенке UTA) | 10 |

### Расстояние primary → secondary (D1)

```
D1 = f − D2 = 1200 − 240 = 960 мм
```

### Принципы крепления трубок

Каждая трубка вставляется в печатный сокет на ~50мм глубину, фиксируется одним сквозным болтом M5 с барашковой гайкой. Снять/поставить = открутить 8 барашков. Коллимация сохраняется, потому что геометрия задаётся жёсткими углами mirror box и UTA, а не положением трубок.
