## Геометрия (контракт)

Все детали проектируются под единые параметры — менять только в одном месте, иначе детали не сойдутся:

```
TUBE_DIAM_MIN = 22.0    # мм, минимальный диаметр стойки (зажим)
TUBE_DIAM_MAX = 28.0    # мм, максимальный
UTA_ID = 240.0          # мм, внутренний диаметр верхней клетки
MIRROR_BOX_INSIDE = 250 # мм, внутренний размер нижней клетки (квадрат)
TRUSS_LENGTH = 900.0    # мм, расчётная полезная длина стойки
HEIGHT_ADJUST_RANGE = 40 # мм, ход регулировки высоты оправы
```

После генерации все скрипты будут в этой же папке (`generate_*.py`).
